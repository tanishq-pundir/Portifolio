# Tanishq Pundir — Portfolio

A design-focused personal portfolio built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

Upload the contents of this folder to a public repository. For a root portfolio URL, name the repository `<your-github-username>.github.io`, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` / root.
